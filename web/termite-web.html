    Importing your paths

    JSON accepts an array of paths or an object with a paths array. Every point contains X, Y and Z in millimetres.

    {"paths":[{"id":"path-1","layer":"Default","points":[[0,0,0],[30,0,0],[30,20,0]]}]}

    CSV format (one row per point, rows grouped by path identifier):

    path,x,y,z,layer
1,0,0,0,Default
1,30,0,0,Default
1,30,20,0,Default

    Use simple unquoted CSV fields. JSON preserves layer names without CSV restrictions. Supported layers are labels only in this build; no extrusion values are inferred. Rhino .3dm, STL and Grasshopper files cannot be imported here yet.

    Save project records both the input and current geometry. Operations affect all paths; selecting a path only highlights it. Maximum import: 20 MB / 200,000 points. Travel optimization: 250 paths.
